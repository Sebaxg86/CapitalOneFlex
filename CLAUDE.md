# Inicio para Claude

Lee y sigue `AGENTS.md`, `PROYECTO.md` y `ARQUITECTURA.md` de esta carpeta. Son la especificación aprobada para construir la demo local; los archivos actualmente son documentación, no código ejecutable.

Implementa el prototipo por las etapas indicadas. Comienza por el motor y su fixture verificable, continúa con persistencia, componentes visuales y las dos tareas de Gemini. La composición dinámica de pantallas es parte obligatoria del alcance, con catálogo cerrado y validación; no la reduzcas a una única plantilla fija.

Con credenciales disponibles, integra Gemini API y Tiger Data realmente. Si faltan, avanza con adaptadores locales explícitos y documenta qué falta para activar y verificar los proveedores. Crea README y scripts de ejecución, ejecuta pruebas y arranca la demo local. No modifiques el proyecto HackOS ni publiques el prototipo.

## Configuración e intervención humana

Leer `CONFIGURACION.md`: obtener claves, preparar `.env.local`, solicitar intervención temprana y verificar ambas integraciones reales. Aplicar su protocolo sin exponer secretos.
